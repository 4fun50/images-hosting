# Images publiques Semzen

Ce dépôt héberge les images publiques utilisées par les signatures e-mail Semzen.

Les fichiers sont servis avec GitHub Pages, par exemple :

`https://4fun50.github.io/images-hosting/agenda-manuscrit-blanc-2.png`

Le dépôt doit rester public pour que les images continuent de s’afficher dans Gmail, Spark et Axonaut.

Les visuels restent la propriété de Semzen. Ce dépôt n’est pas une bibliothèque open source.
